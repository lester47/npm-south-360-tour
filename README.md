# 故宮南院文物小旅行

國小校外教學用的 360° 互動教材：走訪國立故宮博物院南部院區六大展廳（穿越喜瑪拉雅、漁樂圖、揮翰學書、東亞茶文化、天團降臨、佛陀形影），轉動全景找線索、闖關問答，領取「故宮南院文物小導覽員」證書。

- 直接開啟 `index.html` 即可使用（單一檔案，可離線）。
- 六間展廳可自由選擇順序探索；網址加上 `?teacher` 為教師預覽模式。
- 全景展廳為**示意場景，非故宮實景**。文物圖片來自國立故宮博物院 Open Data（CC0）、大都會藝術博物館、NASA 與 Wikimedia Commons，逐件出處見 [SOURCES.md](SOURCES.md)。
- `panoramas/` 為六張 4096×2048 全景原圖；`build/` 為產生全景與頁面的腳本。

本專案與國立故宮博物院無隸屬關係。
